# 共选 · 局域网投票器

一台电脑主持投票，最多登记 10 台 AI Passport。每道题有 2～6 个单选项。同一设备在同一题中首次确认后锁票。主持人可实时查看统计，公布后每台投票器都会收到最终结果。现场运行只需要局域网。

仓库包含 0.3.0 版投票器固件和电脑主持台。设备使用 ESP32-C3、8 MB Flash 和原板的三个按键。板级驱动沿用 [AI Passport](https://github.com/Eason-Xi/ai-passport)，保留原 MIT 许可证。项目最初的需求见[投票器 PRD 重建版](docs/LAN_Voting_PRD_v0.1_重建版.md)。

## 开始一场投票

1. 首次使用请先按下文安装主持软件。在主持电脑启动[主持台](host/start.command)，打开[本机网页](http://127.0.0.1:8765)，记下六位入场码。已运行旧版主持台时，可用原数据库重启新版。
2. 手机相机扫投票器屏幕上的二维码，确认加入设备热点。支持配网弹窗的手机可直接选网。若页面没有弹出，扫设备切换显示的第二个码，或打开[设备配网页](http://192.168.4.1/)。上下键可以切换两个码，热点名和备用密码显示在第一个码下方。
3. 在列表中选现场 2.4 GHz Wi-Fi，输入 Wi-Fi 密码和入场码，点「连接并入场」。开放网络会隐藏密码框，隐藏网络可手动输入名称。设备自动寻找主持电脑。同一网段有多个主持台时，手机会列出各台编号，点选与电脑一致的一项。设备收到主持台确认后才保存配置并重启。密码、入场码或发现失败都可以在原页重试。
4. 在主持台填写题目和选项，选择「截止方式」，点击「发起投票」。默认由主持人手动截止，也可选 30 秒、1 分钟、5 分钟，或指定某天的北京时间，精确到秒。参与者按上下键选择，按确定查看所选项，再按确定提交。确认页面按任一方向键可返回选择。设备显示「投票成功」表示电脑已记票。
5. 「截止收票」会停止接受新票，结果仍只对主持人可见。「公布结果」可以从收票中或已截止阶段执行。设备显示各选项票数、百分比和总票数，上下键可选中长选项滚动阅读。当前结果公布后即可发起下一题。

主持电脑与投票器应在允许互访的同一局域网，电脑可以使用网线。自动发现使用同一 IPv4 子网内的 UDP 48765，投票使用主持台的 TCP 端口（默认 8765）。发现报文只带随机查询值、公开会场编号和端口。投票器会记住配对的会场编号，同一主持电脑换 IP 或端口后可自动重新找到。不同电脑使用新数据库会有不同编号。要主动更换会场，长按确定键并确认重新配网。

若路由器过滤广播，或服务器仍是旧版，展开「手动指定主持电脑」，填私有 IPv4，例如 `192.168.1.20` 或 `192.168.1.20:9876`。电脑端在「参与设备」里可展开查看完整地址。若设备间被访客网络隔离，请改用允许设备互访的网络。手机因切换频道掉线时，可重连原投票器热点。

## 定时收票

选择时长后从发题成功开始计时。选择「指定日期和时间」时，主持台始终按北京时间解释输入。收票中可以在「实时计票 → 调整截止时间」修改时间，或改回「手动截止」。在这里选择时长会从保存设置时重新计时。也可以随时点击「截止收票」提前结束。

主持台显示预定时刻和倒计时，0.3 版投票器在屏幕左上角显示剩余时间。设备通过主持台同步倒计时，无需配置时钟。到点时主持服务主动通知在线投票器，离线设备重连后取得最新阶段。已截止的题目不能延长或重开，点击「公布结果」后参与者才能看到票数。

关闭主持网页不影响截止。电脑休眠或服务停止期间不能接收新票。使用原数据库恢复后，已到期的题目直接进入截止阶段，未来的截止时间继续生效。旧数据库中的已有题目沿用手动截止；原有投票器连接新版主持台也会正常收到截止通知。设备端显示倒计时需要 0.3 固件。

## 主持软件的首次安装

克隆本仓库并安装 Python 3.12，然后在项目根目录运行以下命令。安装依赖需要联网，之后可离线使用。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r host/requirements-lock.txt
.venv/bin/python host/server.py
```

Windows 用 `py -3.12 -m venv .venv` 创建环境，后续两条命令中的 Python 路径用 `.venv\Scripts\python.exe`。参数 `--port` 可更改端口，`--data` 可选择另一场活动的数据库。主持管理页面仅在运行服务的电脑上开放。

## 计票与恢复

| 情况 | 行为 |
| --- | --- |
| 提交时断线或断电 | 投票器在发包前将题号与选择写入 NVS。重启或重连时先取服务器快照，若仍为同一题且开放、服务器未记票，则自动补交原选择。 |
| 同一请求到达多次 | 电脑按「题号＋设备编号」唯一计票，相同选择返回原记录。改选请求会被拒绝。 |
| 截止时仍有未送达的请求 | 由主持电脑在计票事务取得写锁时判定。达到截止时刻即拒绝新票，重发已记票的相同选择仍可拿回原确认。 |
| 电脑服务重启 | 使用原数据库恢复当前题目、收票阶段、入场码和已记票，设备重连后同步。 |
| 设备登记名额已满 | 可在网页移除离线设备，再加入新设备。移除登记不会删票，同一设备重新入场仍受原投票记录约束。 |
| 零票或平票 | 零票显示 0%，平票保留相同票数。网页显示一位小数，投票器显示四舍五入的整数百分比。 |

数据库默认在 `host/data/votes.sqlite3`。需复制数据库时先停止服务，或用 SQLite 的备份接口。现场采用共享入场码和出厂 Wi-Fi MAC 识别设备，适用于可信局域网。多人共用入场码不提供防冒名的身份认证。Wi-Fi 凭据由投票器保存在本机 NVS。

## 中文界面

题目最多 60 字，每个选项最多 24 字。设备与主持台共用 6,994 个可显示字符，包括 GB2312 的 6,763 个汉字、可打印 ASCII 及常用标点。超出范围的字符会在发题时标出。长题目和选中选项会自动滚动。屏幕右上角显示电量，读不到时显示缺省标记。投票时闲置 30 秒、配网时闲置 60 秒会调暗屏幕，调暗后的首个按键仅点亮屏幕。

字体为 18 px、4 bpp 的思源黑体 SC 子集，资源、许可证和生成记录在 [字体资源目录](assets/fonts/)。重新生成需要 `lv_font_conv@1.5.3` 与 `fonttools==4.61.1`。

```sh
python3 tools/gen_vote_font.py generate --font assets/fonts/SourceHanSansSC-Regular.otf --converter /path/to/lv_font_conv.js
python3 tools/gen_vote_font.py check
```

## 验证与刷写

安装上文的主持软件依赖并激活 ESP-IDF 5.5.3，然后在项目根目录运行以下命令。

```sh
./tools/validate.sh
python3 tools/render_vote_preview.py
```

`./tools/validate.sh` 运行投票与发现测试，包括十端计票、定时截止、掉线重连和旧库迁移。它还核对字体、测试镜像校验工具，用隔离配置构建固件并验证合并镜像。只构建固件可运行 `./tools/validate.sh --firmware`。预览脚本用固件实际采用的 LVGL 和字体生成截图，输出在 `build/vote-preview/`。安装 Playwright 和 Chrome 的开发机还可用 `node tools/test_vote_browser.cjs` 检查网页操作与桌面、手机布局。手机相机扫码和系统配网弹窗需实机验证。

ESP32-C3 的 8 MB Flash 使用原 BSP 与原分区表。交付镜像为 `build/FoloToy-AI-Passport-full.bin`，起始地址为 **0x0**。匹配的 ELF、MAP、各段镜像及 SHA-256 清单在 `build/firmware/<合并固件SHA256>/`。复核命令为 `python3 tools/archive_firmware.py verify <目录>`。

0.1、0.2 和 0.3 使用相同的分区和配置结构。保留旧配网信息升级时，可从匹配的归档中仅把应用镜像写入本项目的应用偏移 `0x10000`。原固定地址继续有效，重新配网后可启用按会场自动发现。从 0x0 写入合并镜像可能重置 NVS。须取得本次刷机确认后才写入。实机验收先用一台检查启动、实体三键、中文、电量、配网、倒计时与掉线，再用三台跑完整流程，最后用十台检查同时投票及长时间运行。串口日志提供空闲堆、最大连续块和主任务栈余量。
