## 产品定位与使用场景

一套在同一局域网内使用的软硬件结合多人实时互动投票系统。电脑作为主持端，每位参与者使用一台独立硬件投票器。

## 核心系统架构

电脑端网页控制台通过局域网与多台投票器通信。主持人在电脑上发起投票，投票器接收题目与选项，参与者提交选择；电脑接收并统计投票，公布结果后，各投票器同步显示最终结果。

## 第一版暂定规格

| 项目 | 设计方案 |
| --- | --- |
| 主控芯片 | ESP32 |
| 屏幕 | 1.3～2.0 英寸 |
| 操作方式 | 上、下、确认 |
| 电源 | 独立开关 |
| 通信方式 | Wi-Fi + WebSocket |
| 投票器数量 | 初期目标 10 台 |
| 投票选项 | 2～6 个 |
| 投票规则 | 单选、一机一票 |
| 互联网依赖 | 无 |

具体芯片型号、电池、外壳、成本及最大连接数量仍需确认和测试。

## 投票器硬件与交互

- 使用 ESP32 和小型屏幕。
- 配置上、下、确认三个按键和独立电源开关。
- 屏幕显示题目和选项；参与者通过上下键选择，按确认键提交。
- 主持人公布结果后，投票器同步显示最终结果。

## 电脑端网页控制台

- 创建投票题目和选项，并发送给投票器。
- 实时接收投票，统计参与人数、票数和得票比例。
- 由主持人公布结果，并同步至投票器。

## 投票流程

1. 主持人在电脑端创建投票题目及选项，向投票器发送。
2. 投票器显示题目和选项，参与者使用按键选择并确认提交。
3. 电脑实时接收并统计投票。
4. 主持人公布结果，各投票器同步显示最终结果。

## 局域网通信及边界

- 使用 Wi-Fi 和 WebSocket 在局域网内通信，不依赖互联网。
- 投票采用单选、一机一票。
- 需要考虑断线重连与防重复投票；原文中的具体处理规则和通信协议内容不可见，待确认。
